## 0:00 — 开场（0:35）

各位老师、同学好。我们小组汇报的题目是**基于正交鉴频架构的激光多普勒远程侦听实现**，英文是 Remote Acoustic Sensing via Laser Doppler Vibrometry。

这项工作要回答的问题是：能不能在**不接触**目标的情况下，用激光感知物体表面的微小振动，并进一步还原成**可以播放、可以画谱图分析**的音频。我们用两条实验来验证：一段是**分三段采集的音阶**，用来标定频率是否准确；另一段是**连续人声**，用来证明方法对真实语音也适用。下面按海报从光路、方法到结果的顺序说明。

---

## 0:35 — Introduction（1:25）【指图1、图2】

在安防和结构监测等场景里，振动测量往往要求远距离、非接触。传统加速度计必须贴附在结构上，对不方便靠近的目标很难部署，布线也会带来电磁干扰。

请看海报上的**图1**。我们采用**激光外差干涉**光路：激光器出光后，经分光镜分成参考臂和信号臂。信号臂经过透镜和**两个声光移频器 AOM** 照射待测目标，目标在声波作用下的微小振动会调制返回光的相位；返回光与参考光在光电探测器 **PD** 上发生干涉**拍频**，输出高频电流。光路中加入 AOM，是为了在探测器上形成**稳定的中频载波**，把有用信息主要放在拍频的相位变化上，从而缓解环境温度漂移、运动方向判断困难，以及干涉条纹在峰谷处灵敏度下降等问题。拍频电流随后进入**锁相放大器**，通过正交解调得到**同相分量 I(t)** 和**正交分量 Q(t)**。

**图2** 展示的是实验室实物搭建，光路走向与图1 一致。需要明确的是：到 I/Q 为止，我们得到的仍是**电域测量数据**，还没有完成「振动速度 → 可听音频」的换算；这一部分放在后面的方法与数据处理里完成。

---

## 2:00 — 信号链路：鉴频 → 后处理（2:10）【指 Main Approach 与 Data Processing 框图】

海报上 **Main Approach** 和 **Data Processing** 是两个板块，但实验里实际是一条顺序链路，建议按下面两层理解，避免听起来像两套独立流程。

**第一层对应 Main Approach：从 I/Q 得到振动速度序列。**  
实验室里常用的做法是对 I、Q 做 **atan2** 求瞬时相位，再进行相位解包裹，最后对相位求导得到速度。在散斑比较明显的回馈光场中，包裹相位会在正负 π 附近频繁跳变，解包裹一旦出错，微分就会在宽频带上产生很强的伪峰，音阶亮带和人声结构都会被掩盖。因此我们采用**正交鉴频**：对去均值后的 I、Q 做差分交叉相乘，直接估计角速度，它与靶面振动速度成正比，核心形式是：

> **v(t) ∝ ( I·ΔQ − Q·ΔI ) / ( I² + Q² + ε )**

其中 Δ 表示对时间的差分，ε 用于避免光强接近零时分母发散，前面还有分位削峰等步骤抑制野值。这样做的关键好处是：在笛卡尔域内运算，**不需要相位解包裹**。算到这里，两条验证线得到的是同类型的**速度时域序列 v(t)**，鉴频前端是共用的。

**第二层对应 Data Processing：在 v(t) 上分别做成可听的音阶文件和人声文件。**  
只有完成鉴频之后，才按信号类型做不同的后处理。

对于**音阶标定**，数据来自三段 MAT 文件中的 I/Q，先按采集顺序拼接，并在段与段交界处做大约 **50 毫秒**的交叉淡化，以减轻拼接处的断裂感；然后对拼接后的 I/Q 做正交鉴频，得到 v(t)，再经削峰和宽带通滤波。因为三段采样点数不同，不能简单用「总点数除以 30 秒」作为最终采样率，否则频谱会整体偏低；我们采用**中间段主峰对齐 1000 Hz** 的方式做 **Fs 标定**，使三段主峰落在约 **500 Hz、1000 Hz 和 2000 Hz**。在频谱对齐之后，再做两级降噪：简单降噪用前 0.5 秒估计噪声并谱减，配合固定带通；最终降噪在此基础上按每段谱峰做窄带自适应增强，使分段音阶更清晰。

对于**人声验证**，输入文件已经是鉴频后的波形，这一步**不再重复**从 MAT 做 I/Q 拼接和鉴频，而是直接在 v(t) 上做 **50 到 2000 Hz 带通**，并用**全段各频点的低分位数**估计噪声底进行谱减。人声开头往往已经是语音内容，不适合像音阶那样用固定 0.5 秒当作纯噪声段，所以噪声估计方式与音阶线不同。

总结这条链路：**图1、图2 与锁相完成采集并得到 I/Q；Main Approach 用正交鉴频把 I/Q 变为 v(t)；Data Processing 再在 v(t) 上分支，音阶线负责拼接、Fs 标定和分级降噪，人声线负责带通和谱减。**

---

## 4:10 — Results（1:15）【依次指图4、图5、图6】

实验结果集中在三张图上。**图4** 给出音阶信号的三级语谱对比，从左到右分别是未降噪、简单降噪和最终降噪。可以看到三条水平亮带随处理逐级变清晰，图中的竖线位置对应三段 MAT 数据的分界，说明拼接与分级降噪是有效的。

**图5** 是对应的 Welch 功率谱。三个主峰分别落在约 **500 Hz、1000 Hz 和 2000 Hz** 附近，与标称音阶一致，这表明 Fs 标定策略是正确的，也侧面验证了正交鉴频得到的速度序列在频率轴上是可靠的。

**图6** 展示人声结果，频率范围取 0 到 2000 Hz，上图为降噪前，下图为降噪后。降噪之后，基频轨迹和共振峰结构更容易辨认。结合前面的处理流程可以看到：**音阶和人声共用同一鉴频方法，差异主要体现在鉴频之后的后处理参数**，而不是两套完全不同的解调原理。
