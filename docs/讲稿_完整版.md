## 1. Introduction — 实验背景及原理

### 【简版·建议讲】约 1 分 20 秒 · 指图1/图2

振动测量在安防、结构监测里很重要。接触式传感器要贴附目标，**远距离、非合作目标**不方便，也易受电磁干扰。

我们采用**激光外差 / 回馈干涉**光路（见图1）：激光经分光镜分为**本振臂**和**信号臂**；信号臂经**双 AOM 移频**照到目标，反射光与参考光在 **PD** 上拍频；拍频信号经**锁相放大器**正交解调，得到 **I(t)、Q(t)**。

**I/Q 是后续振动还原的输入**；如何从 I/Q 得到速度，是 Main Approach 的核心。

图2 是实验实物搭建，与图1 原理对应。

---

### 【可选·详细】1-A 为什么要非接触光学测量

- 声波在空气中衰减；LDV 测的是**目标表面**在声压下的**微小位移/速度**。  
- 麦克风：声场；加速度计：要贴附、布线，远距离难。  
- 激光：隔空照射，抗电磁干扰，适合演示「远程监听」类场景。

---

### 【可选·详细】1-B 图1 光路逐点讲解（指图1）

**整体一句：**  
ML 出光 → BS 分光 → 一路本振、一路经 L1→AOM1→AOM2→AP 照目标 T → 返回光与参考光在 PD 拍频。

| 指着 | 说什么 |
|------|--------|
| **ML** | 激光器，角频率 **ω** 的相干光。 |
| **BS** | 分光镜：透射路去目标（信号臂），反射路作本振（参考臂）。 |
| **L1** | 透镜，聚焦/准直，光斑打在目标上。 |
| **AOM1、AOM2** | 声光调制器；上方公式：ω →（AOM1 −1 级）ω−Ω₁ →（AOM2 +1 级）ω−Ω₁+Ω₂。 |
| **AP** | 光阑，挡杂散光。 |
| **T** | 待测目标；声波引起表面振动，调制返回光**相位**。 |
| **ATT** | 衰减片，调节本振强度，避免 PD 饱和。 |
| **PD** | 信号光与参考光干涉**拍频**，输出电流（还不是音频）。 |

**口播串联（约 1 分 20 秒）：**  
激光器出光，分光镜分两路。一路经透镜、双 AOM 移频后照目标；移频公式是 ω 变为 ω−Ω₁+Ω₂。目标振动调制返回光。返回光与本振在 PD 上拍频，得到高频电流，再送锁相放大器。

---

### 【可选·详细】1-C 双 AOM 正、反向经过后的总频移

- **单程（去目标）：** 频移 Δf_去 = Ω₂ − Ω₁  
- **往返（去+回，各经 AOM2、AOM1 一次，同级次）：** 总频移 **Δf_往返 = 2(Ω₂ − Ω₁)**  
- 参考光不过 AOM，频率约 **ω**；拍频约 **2|Ω₂ − Ω₁|**（具体符号以驱动接线为准）。  
- 常令 **Ω₁≈Ω₂**，使拍频落在锁相方便处理的 MHz 段。

---

### 【可选·详细】1-D 「AOM 产生稳定载波，减轻三种问题」是什么意思

**产生稳定载波：**  
AOM 使信号光与参考光在 PD 上产生**固定高频拍频 ω_IF**；振动主要调制拍频的**相位**，不是把载波频率本身变成 500 Hz。

| 问题 | 无/弱移频时 | 有 AOM + 锁相后 |
|------|-------------|-----------------|
| **低频漂移** | 温度、抖动引起慢变，与信号混在一起 | 信息在 MHz 载波上，锁相只提取 ω_IF 附近，慢漂移被抑制 |
| **方向模糊** | 难以区分靠近/远离 | 外差拍频有符号，I/Q 相位旋转方向对应运动方向 |
| **灵敏度衰落** | 干涉曲线峰谷处，微振动不灵敏 | 测拍频相位调制，在射频段高增益检测，避开「最不灵」工作点 |

**口语：** 把信号搬到高频再测，锁相在固定频率上「听」相位变化。

---

### 【可选·详细】1-E 锁相放大器与 I(t)、Q(t)

**PD 电流（拍频项）：**  
**i(t) ≈ I₀ + A·cos(ω_IF·t + φ(t))**  
振动信息在 **φ(t)** 里。

**正交解调（锁相内部）：**  
**I(t) = 低通[ i(t)·cos(ω_IF·t) ]**  
**Q(t) = 低通[ i(t)·sin(ω_IF·t) ]**  
（低通 = 混频后滤除高频，只留慢变包络。）  
近似：**I ∝ A·cos φ，Q ∝ A·sin φ**。

**含义：**

- **I**：同相分量；**Q**：正交分量；合起来是拍频相量 **I + jQ ∝ A·e^(jφ)**。  
- **I、Q 缓慢变化**（kHz 级），才适合后续鉴频与 MAT 处理。  
- 锁相负责：**高频 PD 电流 → 慢变化 I/Q**；还不是最终可听音频。

**【可选·详细】1-F 两束光干涉 → I/Q 公式链（备答/深入）**

1. 参考光 Er = Ar·cos(ωr·t)，信号光 Es = As·cos(ωs·t + φ(t))  
2. PD：i(t) = R·|Er + Es|²，拍频项 ∝ cos(ω_IF·t + φ(t))  
3. 锁相：混频 + 低通 → **I, Q**  
4. 后续鉴频：**v ∝ (I·ΔQ − Q·ΔI) / (I² + Q² + ε)**（Δ 为对时间的差分/微分）

---

## 2. Main Approach — 核心方法

### 【简版·建议讲】约 2 分钟

**传统方法：** atan2(Q,I) → 相位解包裹 → 微分得速度。散斑下相位在 ±π 附近突变，解包裹失败，微分后出现全频带伪峰，音阶/人声被淹没。

**本工作·正交鉴频：** 对去均值后的 I、Q 做差分交叉相乘，直接得角速度（∝ 振动速度）：

> **v(t) ∝ ( I·dQ − Q·dI ) / ( I² + Q² + ε )**

**特点：** ① 无需相位解包裹；② 音阶 + 人声双验证；③ 拼接淡化、Fs 标定、降噪可模块化。

**图2（解调对比）：** 左传统四步 + 问题；右正交四步 + 公式（按海报排版）。

---

### 【可选·详细】2-A 传统 atan 解调四步（对照海报框图）

1. 锁相输出 **I(t)、Q(t)**  
2. **φ = atan2(Q, I)**（包裹相位）  
3. **解包裹** → 连续相位  
4. **v ∝ dφ/dt**  

**问题句：** 散斑 → 相位突变 → 解包裹错 → 微分伪峰。

---

### 【可选·详细】2-B 正交鉴频四步（对照海报框图）

1. **I、Q 去均值**（原点对齐）  
2. **差分** dI、dQ  
3. **I·dQ − Q·dI**（交叉相乘）  
4. **÷ (I²+Q²+ε)** → **v(t)**  

**与 atan 关系：** 在相位连续时 **v ∝ dφ/dt**；散斑时不连续，交叉相乘更稳。

---

### 【可选·详细】2-C 公式与实现细节

- **ε：** 分母防光强趋零发散。  
- **98% 分位削峰：** 鉴频野值抑制（在还原流程里）。  
- **数字实现：** 对 I、Q 序列差分；与 `ldv_restore.py` 中 `(xa*dy-ya*dx)/(xa²+ya²+ε)` 一致。

---

### 【可选·详细】2-D 正交鉴频 vs 采样率 Fs（备答）

- **Fs 标定**只改时间轴/频率轴刻度，**不替代**正交鉴频。  
- **正交鉴频**不从 I/Q **直接输出** Fs；Fs 靠音阶主峰或硬件时钟。

## 3. Data Processing — 数据处理

### 【简版·建议讲】约 1 分 30 秒

**音阶（三步）：**

# 附录 A：常见问题备答（详细）

**Q1：为什么不用 atan？**  
散斑下包裹相位突变，解包裹不稳定；**(I·ΔQ − Q·ΔI) / (I² + Q² + ε)** 在笛卡尔域直接求角速度，不求相位。

**Q2：采样率到底多少？**  
- 导出 WAV（音阶）约 **13397 Hz**，时长约 **20.1 s**，N≈269012。  
- 试探 **Fs_trial = N/30 ≈ 8967 Hz** 仅用于鉴频中间步骤。  
- MAT 未给出统一硬件 Fs；三段 IQ 点数不同。

**Q3：正交鉴频能算 Fs 吗？**  
不能。输出 v(t) 序列；Fs 靠 1 kHz 主峰标定或采集时钟。

**Q4：知道 Fs 就不用正交鉴频？**  
否。Fs 定标度；鉴频定如何从 I/Q 稳定求速度。

**Q5：AOM 往返频移？**  
单程 **Ω₂ − Ω₁**；往返 **2(Ω₂ − Ω₁)**；拍频供锁相。

**Q6：I/Q 是什么？**  
锁相对 PD 拍频做 cos/sin 混频低通后的同相/正交分量，慢变化，承载 **φ(t)**。

**Q7：人声为何不用 0.5 s 谱减？**  
开头可能已是语音；用全段低分位估计噪声更稳。

**Q8：简单和最终降噪？**  
简单=固定带通；最终=按段多峰自适应。

**Q9：自混合还是外差？**  
图1 为**外差**：本振与信号在 PD 拍频；部分光亦可回馈激光腔，实验以 PD 拍频 + 锁相为主。

**Q10：和麦克风有何不同？**  
麦克风测空气声压；LDV 测远处物体表面振动，非接触。
